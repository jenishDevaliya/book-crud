Book Manager System

Learn CRUD Operations with Spring Boot + Thymeleaf

What is CRUD?

  • C Create (Add New Book)
  • R Read (View All Books)
  • U Update (Edit Book Details)
  • D Delete (Remove Book)

Software & Tools Used:

  • Spring Boot
  • Thymeleaf
  • MySQL Database
  • Bootstrap 5
  • Font Awesome Icons

Features:

  • Responsive UI
  • Data Persistence with JPA
  • Auto Table Creation
  • Live Reload with DevTools
